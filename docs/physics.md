# Физика: на что обратить внимание

Чек-лист того, что реально влияет на сечения, с цифрами из расчётов e + Xe⁺.

## 0. Что уже учтено ab initio

* **Гамильтониан Дирака–Кулона** для мишени и для (N+1)-системы, ядро Ферми
  (конечный размер). Спин-орбитальное взаимодействие входит точно через
  уравнение Дирака (jj-связь), а не как поправка Паули.
  Проверка: водородоподобный Xe⁵³⁺ — энергии совпадают с формулой Дирака до
  5·10⁻⁹, отношение малой/большой компоненты — до 7·10⁻⁸ (стресс-тест, раздел 1).
* Остов и валентные орбитали — самосогласованный Дирак–Фок для опорной
  конфигурации иона; никаких модельных потенциалов и подгоночных параметров.
* Обмен электрона с мишенью — полный (антисимметризация), все мультиполи.
* Единственный эмпирический вход — пороги NIST (`exp_energies=True`), можно выключить.

**Не учтено по умолчанию:** брейтовское взаимодействие и КЭД (`mbreit=0` и в
мишени, и в рассеянии — согласованно). Для валентных переходов в Xe это ~1 %
тонкой структуры; включить: `Target(..., hf_args={"mbreit": 1})` и
`Scattering(..., params={"mbreit": 1})` (не проверено в pydbsr).

## 1. Согласованность мишени

**Самое важное.** Состояния одной чётности — в одном КВ-расчёте (см.
[target.md](target.md#один-кв-на-чётность--почему-это-важно)). Иначе они
взаимодействуют через ⟨i|H|j⟩ ≠ 0, которые dbsr_mat3 лишь печатает
(«Target hamiltonian errors»), а в уравнениях появляется паразитная связь.

Цифры для Xe⁺ (J = 0, Ω с основного состояния): раздельные расчёты 6s/5d/7s
против общего КВ — медиана расхождения 21 %, для 5p⁴(³P₂)6s и 5p⁴(³P₁)5d — в 2–2.5 раза.

Проверка: `sc.target_errors()` → `h`, `s` < 10⁻⁴.

## 2. Качество состояний мишени

* **Термозависимость** возбуждённых орбиталей (5d в 5p⁴(³P/¹D/¹S)5d) —
  корреляционная орбиталь (`correlation=`), см. [target.md](target.md).
* **Смешивание конфигураций**: 5s5p⁶ ↔ 5p⁴5d в Xe⁺ сильное — в один КВ.
* **jj-подоболочки**: варьируйте nl и nl- (pydbsr делает это сам).
* Ориентир: ошибки уровней < 0.3–0.5 эВ для важных состояний. Отношения сил
  осцилляторов (dbsr_mult3) — хорошая дополнительная проверка волновых функций
  для дипольных переходов.
* Пороги заменяются на NIST, но **смешивание** состояний определяется расчётом.
  Если состояние сильно ошибается по энергии, его смешивание с соседями и
  сечения тоже ненадёжны.

## 3. Полнота модели сильной связи

* **Какие состояния включать.** Все, между которыми идут заметные переходы в
  нужном диапазоне энергий, плюс состояния выше — они дают резонансы и
  «забирают» поток. Сечение возбуждения уровня, близкого к последнему
  включённому, обычно переоценено. Для Xe⁺: 67 состояний до 5p⁴7s (как Wang 2019).
* **Каскады.** В спектроскопии заселённость верхнего уровня линии идёт и через
  каскады с выше лежащих уровней: для эмиссионных сечений нужно учитывать
  прямое возбуждение + каскады (A-коэффициенты из dbsr_mult3/NIST).
* **Псевдосостояния** (связь с ионизационным континуумом) в pydbsr не
  генерируются; при энергиях выше порога ионизации (21 эВ для Xe⁺) возбуждение
  может быть переоценено на десятки процентов. Это известное ограничение модели
  «только физические состояния» (как и у Wang 2019).
* **Каналы.** pydbsr (dbsr_conf3) включает все каналы, разрешённые моментом и
  чётностью; стресс-тест сверяет с независимым перебором.

## 4. Парциальные волны

* Не дипольные переходы: J ≈ 10–20 достаточно.
* Дипольные: J ≈ 50 и больше при высоких энергиях, или top-up (не реализован).
  Всегда смотрите `cs.omega_pw`.
* Для скоростей при низких Te (2–5 эВ) важна область вблизи порогов, где
  нужны малые J, — они сходятся быстро.

## 5. R-матрица и сетка

* `rmax` (радиус a): орбитали мишени должны обращаться в ноль до a. Для
  ридберговских состояний (n ≥ 8) a растёт как n².
* `hmax`: k_max·hmax ≲ 1 (60 эВ → hmax ≤ 0.5). Иначе сечения при высоких
  энергиях неверны.
* Число сплайнов ns определяет размер матриц; khm ≈ nch·(ns − 6).
* Отрицательно-энергетических (позитронных) решений в разложении нет —
  стресс-тест это проверяет.

## 6. Резонансы и сетка энергий

Ниже каждого порога — ридберговские серии резонансов. Они физические и сильно
влияют на скорости при малых Te. Шаг сетки должен их разрешать или хотя бы
давать правильное среднее (Gailitis): стандарт — 0.001 Ry (0.0136 эВ);
проверяйте сходимость скоростей по шагу.

## 7. Сравнение с экспериментом/другими расчётами

* Сравнивайте в одном диапазоне энергий (скорости интегрируются только по сетке).
* Интенсивность линии ∝ сечение **эмиссии** (с каскадами и коэффициентом
  ветвления), а не прямого возбуждения.
* Для плазмы холловских двигателей ФРЭЭ не максвелловская — есть `bugrova()`
  и любая своя функция.

## 8. Численная точность — проверяет стресс-тест

Сохранение тока (симметрия K до симметризации ~10⁻¹²), унитарность S,
|T|² ≤ 4, Ω ≥ 0, непрерывность на порогах, положительная определённость
матрицы перекрытий, вронскиан кулоновских функций. См. [validation.md](validation.md).
