# Проверка: стресс-тест

```bash
python tools/stress_test.py --target RUN/target --scat RUN/scat [--scat RUN2/scat] \
                            [--skip-matrices] [--log stress_log.json]
```
Проверяет настоящие выходные файлы DBSR, а не модельные данные. Все
предупреждения numpy/Python превращены в ошибки. Код возврата 0 — всё
прошло. Время: ~15–30 мин на две волны с 67 каналами (`--skip-matrices`
убирает самый медленный раздел 5).

Запускайте после первых волн (J = 0) каждой новой модели — это дешевле,
чем обнаружить проблему после недели счёта.

## Что проверяется

| Раздел | Проверки | Типичный результат (Xe⁺, 67 сост.) |
|---|---|---|
| 1. Уравнение Дирака | водородоподобный Xe⁵³⁺, точечное ядро: E(1s, 2p₁/₂, 2p₃/₂) против точной формулы; Q/P против точного; нормировка; P(a)=Q(a)=0 | 5·10⁻⁹; 7·10⁻⁸ |
| 2. Мишень | ядро Ферми; нормировка орбиталей; обращение в ноль на границе; кинетический баланс Q ≈ (P′+κP/r)/2c; спин-орбита остова; тонкая структура 5p⁵ против NIST; сходимость по сетке | 10772 против 10537 см⁻¹ (+2.2 %) |
| 3. Функции Кулона | вронскиан F′G−FG′ = 1 на 2000 точках (l ≤ 60, η до −150); сравнение с mpmath | 2·10⁻¹⁴; 3·10⁻¹³ |
| 4. Внешняя область | симметрия C_λ; полнота набора каналов (независимый перебор); нет отрицательно-энергетических полюсов; потенциал ионизации (N+1)-системы; **симметрия K до симметризации (сохранение тока)** на ~800 K-матрицах, включая энергии ровно на порогах и ±10⁻¹²; унитарность S; \|T\|² ≤ 4; непрерывность на порогах; Ω ≥ 0, Ω_ij = Ω_ji; параллельный = последовательный; сходимость по r_match; размер релятивистской поправки | 2·10⁻¹²; 4·10⁻¹³; IP Xe 12.14 эВ (NIST 12.13) |
| 5. Матрицы dbsr_mat | хранение нижнего треугольника (H, S симметричны по построению); конечность; **S положительно определена** (иначе DPOTRF) | λ_min(S) = 10⁻⁵…10⁻² |
| 6. Мишень глазами dbsr_mat3 | max \|⟨i\|H\|j⟩\|, max \|⟨i\|j⟩\| между состояниями мишени | 0 при КВ на чётность |
| 7. Библиотека | убийство группы процессов по таймауту; распознавание `STOP` DBSR; юнит-тесты с `-W error` | |

Лог эталонного прогона: [stress_test_xe_plus_J0.log](stress_test_xe_plus_J0.log).

## Юнит-тесты

```bash
python -m pytest -q                 # ~35 тестов, из них сквозной расчёт (slow) ~30 с
python -m pytest -q -m "not slow"   # без него
```
Проверяют: кулоновскую фазу рассеяния (одноканальная задача с точным ответом),
пропагатор против прямого интегрирования ОДУ, релятивистскую сшивку,
чтение h-файлов, побайтовое совпадение разбиения состояний с утилитой `jcfile`,
разбор таблиц NIST и xlsx, условия ортогональности, сквозной расчёт e + Xe⁺.
