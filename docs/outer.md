# Внешняя область: K-матрицы, Ω, σ, скорости

```python
out = sc.outer()                                   # или db.OuterRegion.from_files(sorted(glob("scat/h.*")))
E = np.arange(0.01, 60, 0.0136)                    # энергия электрона над основным состоянием, эВ
cs = out.collision_strengths(E, jobs=64, per_partial_wave=True)
cs.save("omega.npz"); cs = db.CollisionStrengths.load("omega.npz")
```

## Что считается

1. R-матрица на границе a из полюсов и поверхностных амплитуд `h.nnn`:
   `R_ij(E) = 1/(2a) Σ_k w_ik w_jk / (E_k − E)`, лог-производная `Y = (R⁻¹ + b)/a`.
2. (опционально, `r_match > a`) распространение Y наружу методом Джонсона
   с дальнодействующими мультипольными потенциалами из `h.nnn`.
3. Сшивка с кулоновскими функциями в открытых каналах и с затухающими в
   закрытых → K (действительная симметричная), `S = (1+iK)(1−iK)⁻¹`, `T = S − 1`.
4. `Ω(i→j) = ½ Σ_J (2J+1) Σ_каналы |T|²`, `σ = πa₀² Ω / (g_i k_i²)`.

### Релятивистская сшивка (по умолчанию)

Внутренняя область DBSR полностью дираковская. Вне r = a большая компонента
подчиняется `P'' = [l(l+1)/r² − 2z(1+e/c²)/r − k²]P`, `k² = 2e(1+e/2c²)`.
pydbsr использует эти k и z; `OuterRegion(..., relativistic=False)` — как в
нерелятивистской программе STGF из пакета DBSR. Разница — фаза k·a·e/4c²
(3·10⁻³ рад при 60 эВ и a = 50 a₀): сумма |T|² ~0.2 %, слабые переходы — до
нескольких процентов.

### Закрытые каналы и пороги

* Затухающее решение: 4-членный ряд ВКБ, где он точен (≤ 2·10⁻⁸), иначе
  функция Уиттекера (mpmath, с кэшем).
* Кулоновские функции — COULFG (Fortran) с проверкой вронскиана, mpmath вблизи
  точки поворота и при |η| > 10⁴.
* Канал ровно на пороге (|k²| < 10⁻¹⁰ а.у.) считается только что открывшимся —
  сечение для иона непрерывно при k → 0⁺.
* Под порогами — ридберговские серии резонансов, сходящиеся к каждому
  следующему порогу. Они физические; их разрешение определяется шагом сетки
  энергий. Для скоростей (интеграл по ФРЭЭ) важен шаг, а не отдельные пики.

## Результаты

```python
cs.names                               # имена состояний (порядок h-файла = порядок энергии)
cs.index("5p5_j3_1")                   # номер по имени; везде можно имя, State или индекс
cs.omega[:, i, j]                      # Ω(E), симметрична по i, j
cs.sigma(i, j)                         # σ(E) в см² (NaN ниже порога); units="pia02" | "a02"
cs.incident_energy(i)                  # энергия налетающего электрона относительно состояния i
cs.upsilon(i, j, T=[5e3, 1e4])         # эффективная сила столкновений Υ(T), T в K
cs.rate(i, j, T=1e4)                   # скорость (Максвелл), см³/с
cs.rate_eedf(i, j, db.outer.maxwell(5.0))     # скорость для ФРЭЭ, Te в эВ
cs.rate_eedf(i, j, db.outer.bugrova(5.0))     # распределение Бугровой (холловские двигатели)
```
`rate_eedf` интегрирует `σ(E)·v(E)·f(E)` по посчитанной сетке: сетка должна
покрывать ту часть ФРЭЭ, что выше порога (при Te = 20 эВ — до ~100 эВ).
Своя ФРЭЭ — любая функция `f(E_эВ)`, нормированная на 1.

## Сходимость — обязательно проверьте

**По J.** С `per_partial_wave=True` есть `cs.omega_pw[E, волна, i, j]` и
`cs.pw = [(2J, чётность), ...]`:
```python
J = np.array([p[0] / 2 for p in cs.pw])
k = np.argmin(abs(cs.energies - 30))
contrib = np.bincount(np.round(2 * J).astype(int), weights=cs.omega_pw[k, :, a, b])
```
Вклад последних J должен быть пренебрежимым. Если он убывает медленно
(дипольный переход при высоких энергиях) — нужно больше J или top-up.

**По радиусу сшивки.** `sc.outer(r_match=2*a)` включает дальнодействующие
потенциалы до 2a; сравните с `r_match=None`. Для Xe⁺ (J=0) разница ~10⁻³.

**По сетке энергий.** Резонансы узкие; для скоростей сравните результаты с шагом
DE и DE/2.

## Параллельность

`collision_strengths(E, jobs=N)` распределяет энергии по N процессам.
Время на K-матрицу: ~0.1–1 с для 70 каналов (растёт с числом закрытых каналов
вблизи порогов, где считается функция Уиттекера). Полная сетка 4400 энергий ×
100 волн — порядка часа на 64 ядрах.

## Низкоуровневые функции

```python
from pydbsr.outer import read_h, kmatrix, t_matrix
hd = read_h(sorted(glob("scat/h.[0-9][0-9][0-9]")))
K, open_channels = kmatrix(hd.blocks[0], hd, etot=hd.etarg.min() + 0.5, symmetrize=False)
```
`symmetrize=False` возвращает K без симметризации — асимметрия показывает
численную точность (стресс-тест требует < 10⁻⁶; обычно 10⁻¹²).

## Ограничения

* Нет top-up по J.
* Дальнодействующие потенциалы после `r_match` не учитываются (в STGF — разложение
  Гайлитиса). Практически: `r_match = 2a…4a` при необходимости.
* Не учтены члены O(z²/c²r²) и множитель (1 + (e − V)/2c²) при переводе Q → P′ на
  границе (~10⁻⁴).
